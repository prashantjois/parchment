Parchment is installed

Open Parchment from your Applications folder.

If you selected the default app option, Markdown files now open in Parchment for the logged-in user.

If you selected the skill option, the skill is in ~/.agents/skills/parchment/SKILL.md for the logged-in user.

For agent integration, use this MCP server command in your client's configuration:

/Applications/Parchment.app/Contents/MacOS/ParchmentMCP

Load the agent skill from:

/Applications/Parchment.app/Contents/Resources/skills/parchment/SKILL.md

Setup instructions are available at:

/Applications/Parchment.app/Contents/Resources/docs/mcp.md
