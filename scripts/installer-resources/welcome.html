Parchment

A local Markdown editor with live preview, themes, comments, and agent integration.

This installer places Parchment in your Applications folder. It includes:

  • The native Mac app and ten light and dark themes.
  • The local MCP helper for agent conversations.
  • The Parchment agent skill and documentation.
  • Support for parchment:// document links.

The Installation Type screen offers three optional checkboxes:

  • Install the Parchment agent skill (selected): copy the skill to ~/.agents/skills/parchment for the logged-in user. A different existing copy receives a backup.
  • Register parchment:// links now (selected): register the installed app with macOS. Skipping this step does not remove existing registration or prevent registration when the app opens.
  • Make Parchment the default app for Markdown files (selected): open .md and .markdown files in Parchment for the logged-in user. The default for .txt files stays unchanged.

The skill and default app options require a logged-in user and the current startup volume. MCP client configuration remains a separate step.

If Parchment is running, quit it before installing this update. Your documents, comments, and saved sessions remain in their existing locations.
