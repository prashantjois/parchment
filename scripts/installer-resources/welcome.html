Parchment

A local Markdown editor with live preview, themes, comments, and agent integration.

This installer places Parchment in your Applications folder. It includes:

  • The native Mac app and ten light and dark themes.
  • The local MCP helper for agent conversations.
  • The Parchment agent skill and documentation.
  • Support for parchment:// document links.

If Parchment is running, quit it before installing this update. Your documents, comments, and saved sessions remain in their existing locations.
